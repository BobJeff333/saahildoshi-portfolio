# Saahil Doshi — Aerospace Engineering Portfolio

A Next.js portfolio documenting aerospace engineering projects through requirements, individual responsibility, design decisions, testing, and measured outcomes.

## Live site

[saahildoshi-portfolio.vercel.app](https://saahildoshi-portfolio.vercel.app)

## Featured work

- **NASA Student Launch Initiative — Project RANCH:** Payload Team Lead for a 92-inch fiberglass launch vehicle that reached a measured 4,274.8 ft final apogee.
- **UGA airfoil research:** XFOIL analysis, Fusion 360 modeling, additive manufacturing, and wind-tunnel validation of control, bio-inspired, and AI-generated airfoils.
- **American Rocketry Challenge:** Co-Captain of a team that placed 24th nationally.
- **ERAS2 ionic-wind aircraft:** Engine-subteam work during a four-week residential engineering program averaging approximately 65 hours per week; the final functioning engine produced 24 g of total thrust.
- **Civil Air Patrol:** Cadet Captain and Squadron Commander responsible for approximately 30 cadets.
- **BEAMS research rocket:** Modular biological-payload vehicle developed within an AIAA-published project; NAR Level 1 certification is in progress.

## Technical stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel Analytics and Speed Insights

## Local development

```bash
git clone https://github.com/saahildoshi/saahildoshi-portfolio.git
cd saahildoshi-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Repository structure

```text
src/app/          Routes and page content
src/components/   Shared layout, animation, and UI components
public/images/    Project photography, CAD, schematics, and data figures
public/*.pdf      Supporting technical reports and presentations
```
